# Portfólio · Julia Brasilio

Site estático (HTML, CSS e JavaScript), publicado pelo GitHub Pages. Toda alteração enviada para a branch `main` atualiza o site em cerca de um minuto.

## Onde editar

| O quê | Arquivo |
|---|---|
| Projetos (textos, fotos, ficha) e contatos | `assets/js/dados.js` |
| Textos da página inicial | `index.html` |
| Cores, fontes e visual | `assets/css/style.css` |
| Fotos | `assets/img/` (JPG com no máximo 1600 px no lado maior) |

Em `dados.js`, os trechos marcados com `A COMPLETAR` ainda esperam informações. Fotos com pessoas só aparecem no site quando marcadas com `autorizada: true`.

## Ver no computador

Abra um terminal nesta pasta e rode `python3 -m http.server 4400`. Depois, acesse http://localhost:4400.
